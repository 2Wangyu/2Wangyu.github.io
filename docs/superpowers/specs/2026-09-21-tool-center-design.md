# 余旺个人网站工具中心设计

## 目标

在现有“作品、关于、经历、工具、联系”个人网站结构中，将工具区从占位展示升级为真正可使用的工具中心。访客点击顶部“工具”后进入独立工作台，可以从工具列表中选择功能，并在同一界面直接操作。

工具中心面向余旺自己的日常使用需求，同时保持公开可访问。第一版全部在浏览器本地处理数据，不上传用户输入，不依赖后端服务，并能够直接部署到 GitHub Pages。

## 方案选择

采用独立的 `tools.html` 工作台，而不是首页弹窗或每个工具一个 HTML 页面。

- 相比首页弹窗，独立工作台能承载更多工具和更复杂的操作界面。
- 相比每个工具一个页面，共享工作台切换更快，也更容易统一搜索、分类和移动端体验。
- 工具通过网址片段定位，例如 `tools.html#json-formatter`，因此可以刷新、收藏和直接分享。

## 信息架构

### 个人网站首页

- 顶部导航中的“工具”链接改为 `tools.html`。
- 首页工具区展示四个真实工具卡片，不再显示“即将上线”。
- 工具卡片可直接打开对应工具。
- 工具区提供“查看全部工具”入口。

### 工具中心

- 顶部保留余旺标识、返回个人主页入口和“本地运行”隐私提示。
- 桌面端使用两栏结构：左侧工具导航，右侧操作工作区。
- 左侧包含搜索框、分类筛选、工具名称和简短说明。
- 右侧显示当前工具标题、说明、输入区、操作区、结果区和清空入口。
- 未选择工具时默认打开“文本统计”。
- 切换工具时更新网址片段，不整页刷新。

### 移动端

- 默认显示当前工具和“选择工具”按钮。
- 点击后打开工具列表面板；选择工具后面板自动关闭。
- 工作区采用单列布局，主要操作按钮始终容易触达。
- 输入框、结果区和按钮不得产生横向滚动。

## 第一版工具

### 文本统计

- 输入任意文本。
- 实时显示字符数、去空格字符数、中文字数、单词数、段落数和预计阅读时间。
- 提供“清空文本”。
- 空输入时全部指标为零。

### JSON 格式化

- 输入 JSON 文本。
- 支持格式化、压缩和复制结果。
- JSON 无效时显示包含位置或语法原因的错误信息，不清空原始输入。
- 示例按钮填充一段安全的本地示例数据。

### 时间戳转换

- 支持秒级与毫秒级时间戳自动识别。
- 时间戳可转换为本地日期时间和 ISO 时间。
- 日期时间可转换为秒级与毫秒级时间戳。
- 无效输入显示明确提示。

### 密码生成器

- 可设置长度 8–64 位。
- 可选择大写字母、小写字母、数字和符号。
- 至少需要选择一种字符类型。
- 支持生成、重新生成和复制。
- 密码只在当前浏览器内生成，不保存。

## 模块边界

- `assets/js/tools/registry.js`：保存工具元数据、分类和模块加载关系。
- `assets/js/tools/app.js`：管理工具选择、网址片段、搜索、移动端列表和共享工作台状态。
- `assets/js/tools/text-stats.js`：只负责文本统计计算和界面。
- `assets/js/tools/json-formatter.js`：只负责 JSON 解析、格式化、压缩和错误状态。
- `assets/js/tools/timestamp.js`：只负责日期时间和时间戳互转。
- `assets/js/tools/password.js`：只负责密码选项、随机生成和校验。
- `assets/css/tools.css`：工具中心专属布局与控件样式；沿用现有网站的颜色和字体变量。

每个工具模块导出统一接口：元数据、`mount(container)` 和可选的 `unmount()`。工具的纯计算逻辑单独导出，便于自动测试，不依赖页面环境。

## 数据与隐私

- 所有文本、JSON、日期和密码均只在当前浏览器中处理。
- 不把输入写入网址、日志、浏览器存储或外部服务。
- 网址片段只包含工具标识，不包含用户数据。
- 剪贴板只在用户主动点击复制按钮时写入，并提供成功或失败提示。

## 错误与状态

- 工具标识不存在时回退到文本统计，并同步修正网址片段。
- 工具运行错误显示在当前工作区，不影响左侧列表和其他工具。
- 搜索无结果时显示空状态和清除搜索入口。
- 不支持剪贴板写入时，保留结果并提示用户手动复制。
- 控件具备可见焦点、标签、键盘操作和状态提示。

## 视觉设计

延续现有“深海信号室”视觉语言：近黑背景、青色信号光、细线网格和档案编号。工具中心更偏实用，不重复动态开场；以清晰的工作台为主，用细微状态光和局部转场保持整体一致。

- 左侧工具导航像一列“设备通道”。
- 当前工具使用青色信号线和编号突出。
- 输入与结果区域使用深色平面和精确边框，不使用常见的圆角白色卡片。
- 操作按钮区分主要动作、次要动作和危险清空动作。
- 切换工具时仅工作区内容淡入，不使用影响效率的大幅动画。

## 测试与验收

- 四个工具的纯计算逻辑分别覆盖正常输入、空输入和无效输入。
- 工具注册表中的标识唯一，并且每个工具都有名称、分类和说明。
- 首页的四个工具入口都指向存在的工具标识。
- 直接访问每个工具网址都能打开对应工作区。
- 未知工具标识安全回退到文本统计。
- 桌面与手机宽度下无横向滚动。
- 键盘可以完成工具选择、输入、执行和复制前的所有操作。
- 减少动态效果模式下不影响工具使用。
- 完整测试通过后，再更新 GitHub Pages 交付包。
